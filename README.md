# 📱 Mobile Sales Dashboard | Power BI

An interactive Power BI dashboard for exploring mobile phone sales performance, customer ratings, payment preferences, and sales trends.

![Mobile Sales Dashboard Preview](Mobile%20Sales%20Dashboard.png)

## 📌 Project Overview

This project presents mobile sales data in an interactive dashboard to help users explore sales performance and identify patterns across products, locations, payment methods, and time.

## 🎯 Project Objectives

- Track overall mobile sales performance.
- Explore sales by mobile brand and model.
- Compare performance across cities.
- Understand customer payment preferences.
- Review customer ratings and sales trends.
- Present business metrics in a clear, visual format.

## 🧰 Tools & Technologies

- **Microsoft Power BI** — dashboard development and data visualization
- **Microsoft Excel** — cleaned dataset
- **GitHub** — project versioning and portfolio hosting

## 📊 Dashboard Highlights

- **Sales Overview:** high-level sales performance metrics.
- **Brand & Model Analysis:** compare mobile brands and models.
- **Geographic Analysis:** explore sales across cities.
- **Payment Analysis:** understand payment method distribution.
- **Customer Ratings:** review customer feedback patterns.
- **Sales Trends:** examine changes across time.

> The dashboard preview above shows the report layout. Open the `.pbix` file in Power BI Desktop to interact with the report.

## 🚀 How to View the Dashboard

1. Download or clone this repository.
2. Open `MS Dashboard.pbix` using **Microsoft Power BI Desktop**.
3. If Power BI asks for a data source, update the source path to the included `Mobile_Sales_Data_Clean.xlsx` file.
4. Refresh the data if needed and explore the report visuals and filters.

## 💡 Business Questions to Explore
